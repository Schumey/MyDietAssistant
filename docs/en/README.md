## Conventions used in the guides

- **Bold** marks buttons, tabs and fields as they are named in the interface.
- A path like *Settings → Optional features* means: open the **Settings** tab at the top and find the **Optional features** card.
- `Code` marks entities, options and values you type exactly as shown.
- Optional features are off by default. Where a guide needs one, it says so at the start under **Prerequisite**.
- The interface text is German by default. In the English interface the labels in these guides are shown in English; if a label looks different, check *Settings → Language and units*.
