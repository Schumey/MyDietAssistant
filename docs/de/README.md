## Schreibweise in den Anleitungen

- **Fett** sind Knöpfe, Reiter und Felder, so wie sie in der Oberfläche heißen.
- Ein Pfad wie *Einstellungen → Zusatzfunktionen* bedeutet: oben den Reiter **Einstellungen** öffnen und dort die Karte **Zusatzfunktionen** suchen.
- `Code` sind Entitäten, Optionen und Werte, die Du genau so eintippst.
- Zusatzfunktionen sind standardmäßig aus. Wo eine Anleitung eine braucht, steht es am Anfang unter **Voraussetzung**.
